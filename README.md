# Калькулятор семейного бюджета

Простое одностраничное приложение для учёта семейных доходов и расходов по месяцам. Работает полностью в браузере, без сервера и установки зависимостей.

## Возможности

- выбор месяца для ведения бюджета;
- добавление доходов и расходов с датой операции;
- раздельные категории для доходов и расходов;
- редактирование и удаление операций;
- подсчёт доходов, расходов, остатка и процента трат;
- фильтрация операций (все / доходы / расходы);
- прогресс-бар использования месячного дохода;
- светлая и тёмная тема;
- сохранение данных в `localStorage` браузера.

## Быстрый старт

1. Склонируйте или скачайте репозиторий.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).

Дополнительная сборка и установка пакетов не требуются.

## Использование

1. Выберите месяц в верхней панели.
2. Заполните форму «Добавить операцию»: тип, название, категорию, сумму и дату.
3. Нажмите «Добавить операцию» — данные появятся в списке и обновят статистику.
4. Для изменения существующей записи нажмите «Редактировать» у нужной операции.
5. Для очистки всех операций за месяц используйте кнопку «Очистить выбранный месяц».

Данные каждого месяца хранятся отдельно. При перезагрузке страницы операции и выбранная тема сохраняются.

## Хранение данных

| Ключ в localStorage   | Содержимое                          |
|-----------------------|-------------------------------------|
| `monthlyFamilyBudget` | массив всех операций                |
| `budgetTheme`         | `light` или `dark`                  |
